C. Aktivitas 1 — Eksperimen 10 + 20

Jangan jalankan dulu. Prediksikan hasilnya:

let a = "10";
let b = "20";
console.log(a + b);

Apa output program?

1020

Mengapa hasil tersebut terjadi?

Karena "10" dan "20" ditulis dengan tanda kutip sehingga bertipe String. Operator + pada String menggabungkan teks (concatenation), bukan menjumlahkan.

Apakah a dan b bertipe Number?

Bukan. Keduanya bertipe String.

Uji sekarang. Apakah prediksimu benar? Jelaskan.

Jawaban bergantung pada prediksi siswa. Jika memprediksi 30, prediksi salah karena hasil aslinya "1020". Jika memprediksi 1020, prediksi benar karena + menggabungkan dua String.

D. Aktivitas 2 — Menemukan Tipe Data

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
VariabelPrediksiHasil typeofKesimpulan

nama: prediksi string, hasil "string", kesimpulan: teks yang diapit tanda kutip adalah String.
umur: prediksi number, hasil "number", kesimpulan: angka tanpa tanda kutip adalah Number.

Temuan: apa perbedaan String dan Number berdasarkan eksperimenmu?

String adalah data teks (ditulis dengan tanda kutip) dan dioperasikan sebagai teks. Number adalah data angka (tanpa tanda kutip) yang dapat dihitung secara matematis. Operator + pada String menggabungkan, pada Number menjumlahkan.

E. Aktivitas 3 — Konversi String menjadi Number

Perbaiki program agar menghasilkan 30. Gunakan Number(). Kode di bawah sudah dilengkapi, silakan jalankan.

let a = "10";
let b = "20";
let hasil = Number(a) + Number(b);
console.log(hasil);

Catat hasil program:

let hasil = Number(a) + Number(b);
Hasil program: 30

F. Aktivitas 4 — Program Kasir Sederhana

Program meminta harga dan jumlah lewat prompt(), mengubahnya menjadi Number, lalu menghitung total. Bagian kosong sudah dilengkapi.

let harga = Number(prompt("Masukkan harga: "));
let jumlah = Number(prompt("Masukkan jumlah: "));
let total = harga * jumlah;
console.log("Total belanja = " + total);

G. Tantangan — Program Hitung Nilai

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input dengan Number(), lalu hitung rata-rata: (tugas + UTS + UAS) / 3.

Algoritma saya:

Coba tulis kodenya di sini:

let tugas = Number(prompt("Nilai tugas: "));
let uts = Number(prompt("Nilai UTS: "));
let uas = Number(prompt("Nilai UAS: "));
let rata = (tugas + uts + uas) / 3;
console.log("Rata-rata = " + rata);
Algoritma:
  1. Minta input nilai tugas, UTS, dan UAS dengan prompt().
  2. Ubah ketiga input menjadi Number dengan Number().
  3. Hitung rata-rata = (tugas + uts + uas) / 3.
  4. Tampilkan rata-rata dengan console.log().
let tugas = Number(prompt("Nilai tugas: "));
let uts = Number(prompt("Nilai UTS: "));
let uas = Number(prompt("Nilai UAS: "));
let rata = (tugas + uts + uas) / 3;
console.log("Rata-rata = " + rata);
Contoh: 80, 70, 90 → rata-rata 80.

H. Think — Pair — Share

Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?

Karena prompt() selalu menghasilkan String, walaupun yang diketik berupa angka. Agar bisa dihitung secara matematis, nilainya harus diubah menjadi Number.

Apa perbedaan "10" dengan 10?

"10" adalah String (teks) dan 10 adalah Number (angka). "10" + "10" menghasilkan "1010", sedangkan 10 + 10 menghasilkan 20.

Apa yang terjadi jika lupa Number()?

Operator + akan menggabungkan teks, sehingga hasil perhitungan salah. Misalnya "10" + "20" menjadi "1020". Catatan: operator * atau - tetap mengubah String ke angka secara otomatis, tetapi sebaiknya konversi ditulis eksplisit dengan Number().

Pair: bandingkan jawaban dengan teman. Apakah sama? Mengapa bisa berbeda?

Jawaban terbuka. Perbedaan wajar muncul dari cara menjelaskan; yang penting konsepnya sama: prompt() menghasilkan String dan perlu dikonversi dengan Number().

Share: satu temuan penting untuk kelas.
